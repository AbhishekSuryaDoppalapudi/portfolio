# Abhishek Surya Doppalapudi: Portfolio

Personal portfolio site: delivery and resource leadership on SAP HANA and Snowflake data programs.

- `index.html`: the portfolio (single page, no build step).
- `assets/css/style.css`: styles. Colors are CSS variables at the top; dark mode follows the system setting.
- `assets/img/abhishek.jpg`: profile photo (4:5 portrait, 560×700).
- `My Resume Page/`: the earlier version of the site, kept for reference.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Live at **https://abhisheksuryadoppalapudi.github.io/portfolio/**.

GitHub Pages publishes the `Final` branch, folder `/ (root)` (**Settings → Pages**). All changes go to `Final`; a push updates the live site within a minute or two.

## Updating content

All text is in `index.html`, one `<section>` per part of the page (About, Selected work, Experience, Skills, Certifications, Contact). Keep it in step with the current CV.
